# MMM community health files

Defaults that apply to every MyMediaMatters repo that has no template of its own.

- `ISSUE_TEMPLATE/request-for-kelsey.yml`: the "Request for Kelsey" issue form. It assigns Kelsey and asks GitHub to add the issue to the MMM Work board (`MyMediaMatters/1`).

To send Kelsey a request: open a new issue in the repo it is about and choose **Request for Kelsey**.

Keep this repo free of secrets and client details: it is public so GitHub applies it org-wide.
